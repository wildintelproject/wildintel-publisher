# wildintel-publisher-web

Web version of [wildintel-publisher](../README.md) — a FastAPI backend + React frontend,
built with the same technology stack and visual style as
[wildintel-trapverify](https://github.com/wildintelproject/wildintel-trapverify).

## Quick start

```bash
uv sync
cd frontend && npm install && cd ..
uv run wildintel-publisher-web dev
```

Then open http://localhost:5174.

See `uv run wildintel-publisher-web --help` for all available commands.
